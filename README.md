# Smart-digital-doorbell
Arduino based digital doorbell with LED indication, buzzer alerts and visitor counting.

## Wokwi Simulation

[Click here to run the Smart Digital Doorbell](https://wokwi.com/projects/478597184928710657)

## Features
- Push-button doorbell
- Buzzer sound alert
- LED indicator
- Visitor count displayed in the Serial Monitor

## Components
- Arduino Uno
- Push button
- Buzzer
- LED
- Resistor
